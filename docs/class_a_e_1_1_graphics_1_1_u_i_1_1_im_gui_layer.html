Detailed Description

Manages Dear ImGui integration for debugging and tools.

The ImGuiLayer provides immediate mode GUI functionality:

  • Debug windows and tools
  • Real-time property editing
  • Performance monitoring
  • Custom editor tools
Note
This layer typically runs as an overlay to render on top of other layers
