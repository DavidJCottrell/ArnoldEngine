Detailed Description

OpenGL implementation of the RendererAPI interface.

Provides concrete OpenGL implementations for all rendering operations defined in the RendererAPI interface. This class:

  • Manages OpenGL state for clearing and drawing
  • Handles OpenGL-specific buffer operations
  • Implements indexed drawing using OpenGL vertex arrays
